# Beer Pong

A mobile paddle beer pong game. Flick upward to serve or return, within one quarter-screen width of the ball. Closer contact improves aim. Flick direction controls aim and length controls bounce depth.

Hit the cup for one point; sink it to win. The cup's owner serves next. A serve cup hit scores for the receiver. The Viner rule prevents either player winning their fifth point from a serve cup hit.

Static HTML and three JPEG textures. No build step, dependencies, or API keys. GitHub Pages serves the root of main.
